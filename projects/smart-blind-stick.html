Smart Blind Stick

Arduino-based assistive device designed to help visually impaired individuals navigate more safely by detecting obstacles and environmental hazards.

COMPLETED Arduino GPS GSM Sensors Embedded C
GitHub All Projects

Overview

Smart Blind Stick is an assistive technology project designed to help visually impaired people navigate safely. The system detects obstacles and environmental hazards using sensors and provides alerts through a buzzer.

The project combines embedded programming, sensors, GPS tracking, and GSM communication into a compact assistive hardware system.

Features

Obstacle Detection

Uses the HC-SR04 ultrasonic sensor to detect obstacles in front of the user.

Water Detection

Detects water and wet surfaces such as puddles to help identify environmental hazards.

Audio Alerts

Provides warning signals through a buzzer when hazards are detected.

GPS Tracking

Uses the NEO-6M GPS module to obtain the device's location.

Emergency GSM

Uses the SIM800L GSM module for emergency communication and location-based alerts.

Embedded Control

Arduino UNO coordinates the sensors, alerts, GPS, and GSM communication.
