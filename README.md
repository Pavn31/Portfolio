# Pavan Badiger — Portfolio

A responsive, animated personal portfolio for Pavan Badiger, an Artificial Intelligence and Data Science student at Angadi Institute of Technology and Management in Belagavi.

## Pages

- `index.html` — introduction, about, and contact
- `projects.html` — selected projects with links to their GitHub repositories

## Features

- Responsive layouts for desktop and mobile
- Bright and dark themes with the selection saved in the browser
- Scroll and entrance animations that respect reduced-motion settings
- Project imagery stored locally in `assets/`

## Run locally

From this directory, start a static web server:

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.
