# Pavan Badiger · Portfolio

> Curious by nature. Builder by choice.

A cinematic personal portfolio for **Pavan Badiger**, an Artificial Intelligence & Data Science student at Angadi Institute of Technology & Management, Belagavi.

**Live site:** [pavn31.dpdns.org](https://pavn31.dpdns.org)

## Highlights

- Dark space-inspired visual system with scattered stars and nebula gradients
- CSS-built floating spaceship and orbital hero artwork
- Layered 3D depth, glass surfaces, hover states, and tactile buttons
- Responsive project, About, and Contact sections
- Direct links to GitHub, LinkedIn, and email
- Accessible focus states and reduced-motion support
- Framework-free and build-free: HTML, CSS, and vanilla JavaScript

## Tech stack

- HTML5
- CSS3: custom properties, Grid, Flexbox, 3D transforms, and animations
- Vanilla JavaScript
- Google Fonts: Unbounded and DM Mono

## Project structure

```text
.
├── index.html        # Page content and semantic structure
├── style.css         # Space theme, layout, 3D effects, and responsive rules
├── script.js         # Hero tilt, card interactions, and back-to-top behavior
└── assets/
    ├── Icon.jpeg     # Favicon
    └── Profile.jpeg  # Hero profile image
```

## Run locally

No dependencies or build step are required.

```bash
git clone https://github.com/Pavn31/portfolio.git
cd portfolio
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.

You can also open `index.html` directly, although a local server is recommended for a closer production-like experience.

## Customise it

- Update the page copy, projects, links, and contact details in `index.html`.
- Change the color palette from the `:root` variables in `style.css`.
- Replace `assets/Profile.jpeg` to update the hero portrait.
- Replace `assets/Icon.jpeg` to update the favicon.
- Adjust the space, ship, and 3D motion rules near the bottom of `style.css`.
