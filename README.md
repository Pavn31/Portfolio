## What this is

A cinematic, dark personal portfolio built from scratch with semantic HTML, custom CSS, and vanilla JavaScript. It is designed to feel like a personal command centre: part profile, part project archive, part contact point.

## Visual language

- Dark canvas with layered gradients and a focused visual hierarchy
- CSS-built floating spaceship and orbital hero artwork
- Layered 3D depth, glass surfaces, and tactile hover states
- Warm orange and electric blue accents over deep navy surfaces
- Responsive layouts for desktop, tablet, and mobile
- Accessible focus states and reduced-motion support

## Run locally

No dependencies or build step are required.

```bash
git clone https://github.com/Pavn31/portfolio.git
cd portfolio
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Customise

- Edit copy, projects, links, and contact details in `index.html`.
- Change the palette from the `:root` variables in `style.css`.
- Replace `assets/Profile.jpeg` to update the hero portrait.
- Replace `assets/Icon.jpeg` to update the favicon.
- Tune the spaceship and motion rules near the bottom of `style.css`.
